# DMP_Project_Amalia_Szilagyi
Arduino Flood Protection System

1. Project Overview

My project is designed to monitor water levels and operate a flood barrier when the predefined threshold is exceeded.

2. Project Objectives
   
- monitor water level using a water sensor
- displaying the level of the water on an LCD (low, medium, danger zone)
- if the the water reaches critical level a buzzer sounds
- before the servo motor closes the gate, a countdown is shown on an ssd
- the threat is also shown by 3 LEDs (green=low, yellow=medium, red=danger zone)
- the barrier can be operated automatically and also manually by a button

3. Hardware Components

-Arduino Uno
-Water Level Sensor
-Seven-Segment Display
-Breadboard and Jumper Wires
-LCD
-LEDs
-Buzzer
-Micro Servo Motor
-3 LEDs
